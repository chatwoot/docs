A terminal client for Chatwoot. Most things you'd do in the agent dashboard (read conversations, reply, assign, resolve) work as commands you can script or pipe into other tools. You can also search help center articles from the terminal. It works across every account you belong to, on as many instances as you use (Chatwoot Cloud, staging, self-hosted), and you can paste a dashboard link straight into a command. It's handy with coding agents: tools like Claude Code or Cursor can call `chatwoot` directly to look up conversations, post replies, search help center content when asked, or automate repetitive triage, without needing a custom integration.

- **[Commands](/cli/commands)** — the full command reference: conversations, contacts, inboxes, agents, help centers.
- **[Multiple accounts](/cli/accounts)** — several accounts and instances, `@name`, and pasted dashboard links.
- **[Scripting & output](/cli/scripting)** — JSON / CSV / quiet mode, shell completions, automation recipes.

## Install

```bash
# macOS / Linux
curl -fsSL https://chwt.app/install-cli | sh
```

Installs to `~/.local/bin/chatwoot`. Override with `CHATWOOT_VERSION` or `CHATWOOT_INSTALL_DIR`:

```bash
CHATWOOT_VERSION=v0.2.0 CHATWOOT_INSTALL_DIR=/usr/local/bin curl -fsSL https://chwt.app/install-cli | sh
```

**Windows:** download `chatwoot_<version>_Windows_x86_64.zip` from the [releases page](https://github.com/chatwoot/cli/releases/latest) and extract `chatwoot.exe`.

**From source** (Go 1.25+):

```bash
go install github.com/chatwoot/cli/cmd/chatwoot@latest
```

## Log in

```bash
chatwoot auth login                          # asks for the URL (default: https://app.chatwoot.com)
chatwoot auth login staging.chatwoot.com     # or pass it; any dashboard link works too
```

You'll be asked for your **access token**, from your profile settings in Chatwoot. The CLI validates it, then registers every account you belong to on that instance under a short name (`acme`, `globex-inc`) and asks which one is your default. Log in again to add another instance; see [Multiple accounts](/cli/accounts).

The token is stored in your OS keyring; non-secret config lives at `~/.chatwoot/config.yaml`. For CI or headless use, set `CHATWOOT_API_KEY` to override the saved token.

```bash
chatwoot auth status     # who am I, which instance and account
chatwoot accounts        # your accounts (* = default)
chatwoot auth logout     # remove saved credentials
chatwoot config view     # show config and credential source
```

## First commands

```bash
chatwoot convs                                 # your open conversations
chatwoot conv 123 reply "Looking into it"      # reply to one
chatwoot @acme convs                           # same list, in another account
chatwoot https://app.chatwoot.com/app/accounts/1/conversations/123   # paste a dashboard link
```

Commands run against your default account unless you name another with `@name`. See [Multiple accounts](/cli/accounts).

## Shell completions

The install script offers to set this up interactively. To do it manually:

```bash
# bash
chatwoot completion bash -c > ~/.local/share/bash-completion/completions/chatwoot

# fish
chatwoot completion fish -c > ~/.config/fish/completions/chatwoot.fish

# zsh — append a source line to your .zshrc
echo 'source <(chatwoot completion zsh -c)' >> ~/.zshrc
```

Restart your shell (or `source` your rc file). Tab-completion works for commands, subcommands, and flags. Run `chatwoot completion --help` for details.

## Uninstalling

```bash
chatwoot auth logout              # remove API key from the OS keyring
rm -rf ~/.chatwoot                # delete config (~/.chatwoot/config.yaml and its backup)
rm "$(command -v chatwoot)"       # delete the binary
```

If you set up shell completions, also remove them:

```bash
rm -f ~/.local/share/bash-completion/completions/chatwoot   # bash
rm -f ~/.config/fish/completions/chatwoot.fish              # fish
# zsh: delete the `source <(... completion zsh -c)` line from ~/.zshrc
```

On Windows, delete the extracted `chatwoot.exe` and the `%USERPROFILE%\.chatwoot` folder. If `CHATWOOT_API_KEY` or `CHATWOOT_ACCOUNT` is set in your environment, unset it in your shell rc — `auth logout` can't remove env-provided credentials.
